# Licensed knowledge API example

`checkin.json` and `checkout.json` are legacy v0.1 research fixtures illustrating a possible license-session offer and checkout. They are not consumed by the current x402 Exact runner, are not an executable service, and do not demonstrate a completed payment integration.

See [the License Profile](../../spec/PROFILE-LICENSE.md) and [the experimental registry](../../contracts/license/experimental/ALSPRegistry.sol).
