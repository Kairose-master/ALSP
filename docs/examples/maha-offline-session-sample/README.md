# Maha Strategies offline ALSP sample

This synthetic state-machine sample is based on ALSP main SHA 545221097a48cb6480c58b5d43e05f302acef30f. The files are published on the [maha-offline-session-sample-2026-10-12 branch](https://github.com/Kairose-master/ALSP/tree/maha-offline-session-sample-2026-10-12/docs/examples/maha-offline-session-sample). samples.json contains native Journal.export() results. maha-public-mapping.json is a separate, non-normative companion: it maps public Maha offer details to nearby ALSP fields and records fixture-only settlement and delivery observations.

The generator runs the current main implementations of Journal, SessionClient, x402Transport, verifyReceipt, verifySettlement, and the EIP-3009 signer. The fetch adapter and JSON-RPC ledger are in-process mocks. It does not call Maha, Base RPC, a facilitator, or any public paid endpoint. The authorization signer is a public throwaway fixture key and has never been funded. No provider signature, live settlement, or semantic output verification is claimed.

## Run

From the ALSP repository root:

    npm install
    npm run build
    ALSP_ROOT="$PWD" node docs/examples/maha-offline-session-sample/generate.mjs

The generator asserts the state transitions and archive hash chains before writing both JSON files. Session IDs and authorization nonces are generated by the library, so the scenarios are reproducible but each run produces different bytes.

When running from a separate ALSP checkout, build that checkout first and set ALSP_ROOT to its absolute path before running generate.mjs. The default uses the verified source mirror beside this sample directory when present; otherwise it uses the containing ALSP repository.

## Scenarios

- nativeExports.success: synthetic HTTP 200 body plus mock settlement; native call becomes VERIFIED.
- nativeExports.noWireAndUnrecoverableOutput: the mock ledger settles, but the send throws before ALSP captures any WireResponse; replaying the same request key does not submit or sign again, and reconciliation without a response remains RECONCILIATION_REQUIRED. The native archive has no transaction or settlement proof in this case; the mock transaction is recorded only in the companion file.
- nativeExports.lostThenBodylessRecovery.beforeRecovery and .afterRecovery: the same call is first unresolved with no wire, then the fixture supplies an HTTP 200 WireResponse with body: null and valid mock settlement evidence. Unsigned verifyReceipt accepts canonical JSON null, and the library's settlement verifier accepts the mock RPC record. The call becomes VERIFIED without a second payment and without recovering output content.
- nativeExports.directHttp200NullBody: the actual ALSP transport receives an empty HTTP 200 body, converts it to null, and the unsigned verification path marks the call VERIFIED when the mock settlement checks pass.

VERIFIED is not a delivery or answer-authenticity state. The native export has no separate settlement and delivery status. In the two null-body cases, the returned body is absent; the mock only proves that the library accepted a bodyless wire record plus mock settlement. The field verification: "rpc-confirmed" is the library verifier's label, but its RPC input in this fixture is synthetic and local; it is not Base-chain evidence.

## Maha fit and field boundaries

The companion mapping uses the public context-compression metadata supplied for this review: resource https://www.mahastrategies.com/api/v1/compress, offer metadata version 2026-08-10, eip155:8453, USDC, payee, and amount 1000 base units. The metadata and catalog versions are not signed ALSP terms.

The current ALSP input normalizer returns flat strings and requestUrl() appends them to the resource URL. The current POST transport does not serialize a JSON body. This fixture therefore routes a serialized synthetic payload through a query parameter to exercise the library state machine; it does not meet Maha's nested POST JSON request contract and is not an endpoint interoperability test. The response object is explicitly synthetic; no Maha output schema is invented.

Native requestHash is SHA-256(canonical({endpoint, input: normalizedInput})), not a bare input digest and not Maha's inputHash. Unsigned receipt.requestId is locally generated as unsigned:<nonce>, not a provider purchase ID. The ordinary native archive includes the raw request input and a captured response body when one exists; the sample uses synthetic text only. The companion fields offerId, metadata version, fixture settlement state, and delivery observation are annotations, not native ALSP guarantees.

No signed provider price agreement is used. The experimental bilateral price agreement demo is separate and is not part of this comparison.
